# DocumentList

Downloads for one product, filtered by Tabs (All, Datasheets, Manuals, Certificates, CAD) with counts.

Each row: a file-type tile (mono 9px, `border`, `r-2`), the document title in weight 560, a mono meta line in `text-3` with revision, ISO date, languages and size, and a download icon. Rows hover to `subtle`. The whole row is the link.
