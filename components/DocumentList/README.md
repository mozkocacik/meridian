# DocumentList

Downloads for one product: datasheets, manuals, certificates, CAD files. Tabs filter by type and show a count.

Each row: file type box (PDF, STP, DXF) in mono 9px, name in 560, metadata in `data` 12px (`text-3`): revision, date (YYYY-MM-DD), language, size. A download icon at the right. The whole row is the link.

**Content:** name, file type, revision, date, languages, size.
