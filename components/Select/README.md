# Select

A native select styled like TextField: 40px, `r-2`, `border-strong` edge, a Lucide chevron on the right. Label above. Use it for 4 to 15 options (region, sort order); fewer options use SegmentedControl, more use a searchable list.

In toolbars it may be 32px high without a visible label; then it needs an `aria-label` ("Sort").
