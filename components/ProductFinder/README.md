# ProductFinder

Parametric search for a product category. Filter panel left (260px, `subtle`), results right.

- **Facets:** overline title, checkboxes with counts, range inputs with units.
- **Results bar:** count of results, sort select.
- **Active filters:** chips with a remove icon.
- **Table:** compare checkbox, part number, the defining specs, lifecycle.
- **Pager:** row range left, pages right.

Below 1024px the facets move into a "Filters" button with the count of active filters.

**Content:** facets with values and counts, result rows.
