# ProductFinder

Engineers search for one part by its parameters. The finder puts the filters left (from 1024px; below that a "Filters" button with the count), the result count and sort on top, active filters as removable chips, and a table of products.

- Facets on `subtle`: Checkbox groups with result counts, and number ranges with units inside the fields.
- Results table: compare checkbox, thumbnail drawing, part number in mono, key values, lifecycle badge.
- The footer bar shows how many products are selected for comparison and the pager (current page in `inverse`).
