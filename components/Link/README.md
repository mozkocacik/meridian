# Link

Links go to another page. Two forms.

- **Text link** (`md-link`): inside running text and notices. `text` color with a 1px `border-strong` underline at 3px offset; on hover the text and underline turn `accent`.
- **Arrow link** (`md-link-arrow`): a standalone call to the next page ("View product", "Quote"). Weight 560, a Lucide arrow after the label, `accent` on hover.

The consumer gives the label and the target. Never use an arrow link inside a sentence.
