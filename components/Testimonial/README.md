# Testimonial

One customer quote with the person's name and role. No photos: an initials circle (neutral-soft, ink-secondary, line border) stands in for the face.

The quote uses the `quote` style (24px, 500) in ink, max 768px wide. Name is 16px 600 ink; role is 14px ink-muted, as "Role, Company".

Use one per section, left aligned or `align: 'center'` in a centered band. Use a real quote from a real customer, with permission; do not invent one for a live page. Keep it under 200 characters.

**Content:** the quote (without quote marks), the name, the role, optional initials and the alignment (left or center).
