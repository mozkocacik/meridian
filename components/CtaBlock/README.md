# CtaBlock

The closing call to action: a dark block (inverse-surface, radius-2xl, space-16 padding) with an H2, one line of text and two buttons.

The H2 uses `heading-2` (36px) in inverse-ink. The text is 18px inverse-muted. Buttons: inverse "Talk to sales" first, primary "Get started" last. In the dark theme the block is a raised panel with a line edge, so it stays visible on the dark page.

**Content:** a title, a body, and the button labels and links. Use one per page, above the footer.
