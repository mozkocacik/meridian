# LifecycleBadge

Every product shows its lifecycle state. A 22px badge, radius `r-1`, a 6px dot and a word; the color is never the only signal.

| state | tokens |
|---|---|
| Preview | `info` on `info-subtle` |
| Active | `success` on `success-subtle` |
| NRND | `warning` on `warning-subtle` |
| End of life | `danger` on `danger-subtle` |
| Custom | `text-2` on `muted` |

Certification and standard tags (`md-tag`: ISO 16750, E-mark, AEC-Q100, RoHS) are outlined with `border` and carry no status color.
