Overview

Four buses in, only the frames you choose out

CGW-4 connects four CAN or CAN FD networks and forwards frames by rules you define.

40µs

Routing latency

Typical value, CAN to CAN at 500 kbit/s, 8 bytes. Maximum 80 µs.

1,024rules

Routing table

Filter by ID and mask, 11-bit and 29-bit.

4 × 1kV

Isolated channels

A fault on one bus stays on that bus.

100%

Bus load capacity

No frame loss at full load on all four channels.

CAN FD to classic CAN

Connect a new CAN FD control unit to an existing classic CAN network. The gateway converts frames with up to 8 data bytes.

ID translation

Change the ID of a frame or pack signals into a J1939 PGN, without a firmware change in the control units.

Diagnostic separation

Let diagnostic requests through from the OBD connector and block all other traffic.
