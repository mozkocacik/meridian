# Icon

Lucide icons (lucide.dev), drawn with currentColor, round caps and joins, stroke 1.5, on a 24px grid.

Use 20px in content, 16px in buttons, chips and links, 24px in navigation. Icons are decorative (`aria-hidden`); the text next to them carries the meaning. An icon-only button needs an `aria-label`.

Common names: search, menu, globe, download, maximize-2 (compare), chevron-right, arrow-right, x, info, triangle-alert, check, filter, truck, box, shield, cpu, plug, thermometer, file, moon, sun.

**Content:** one Lucide icon name and a size.
