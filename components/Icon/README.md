# Icon

Lucide icons (lucide.dev), drawn with currentColor, round caps and joins, 24px grid.

Use stroke 2 in buttons, pills and fields (16 to 20px) and stroke 1.8 in icon tiles (22px). Icons are decorative (`aria-hidden`); the text next to them carries the meaning. The logo mark is not an icon; see Logo.

**Content:** one Lucide icon name, with a size and a stroke width.
