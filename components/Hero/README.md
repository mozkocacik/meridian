# Hero

The opening section: announcement pill, H1, a one-line subtitle and two buttons, centered.

- H1 uses the `display` style (60px, 600, -0.03em, 1.1), max width hero-title-max (880px).
- The subtitle uses `lead` (20px, 1.55) in ink-muted, max width lead-max (640px). One sentence, two at most.
- Buttons: secondary "Watch demo" with the play icon first, primary "Start for free" second.
- Padding: space-24 top, space-16 bottom.

**Content:** the title, the subtitle, an optional AnnouncementPill and the actions (two Buttons). Write the H1 as a plain promise, not a slogan.
