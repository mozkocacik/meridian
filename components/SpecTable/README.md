# SpecTable

The full technical data. Groups (CAN interfaces, Power, Environment …) with an uppercase group row and a 1.5px `text` rule. Label column 38% in `text-2`, value column in `text`. Notes under a value in 13px `text-3`.

No outer border. On wide screens put it in the right 8 columns, with a sticky group list and a datasheet button in the left 4 columns.

**Content:** groups of label, value and optional note. Every value has a unit.
