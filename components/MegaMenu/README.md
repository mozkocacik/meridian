# MegaMenu

Opens under the NavBar on hover or click on Products. Three columns of product groups, each with an overline and items (name 15px 560, description 13px `text-3`). The fourth column features one product with a drawing, a lifecycle badge and a link.

`canvas` fill, `shadow-2`, `t-slow` to open. On phones the menu is a full-screen list.

**Content:** groups with items, and one featured product.
