# SegmentedControl

Two to four options where exactly one is on, as buttons with `aria-pressed` in a labelled group. Use it for the monthly and yearly price switch, or to switch a code sample between languages.

The track is surface-soft with a line border and radius 10px. The selected option is surface-raised with a line-control edge and ink text; the others are ink-muted. An option can carry an accent badge ("Save 20%").

**Content:** an accessible name, the options (label, optional badge) and the selected option. Do not use it for navigation between pages.
