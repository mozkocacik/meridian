# ProductFrame

A framed mock of the product: a surface-soft bezel (radius-2xl, space-3 padding, shadow-frame) around a window (radius-lg) with a 220px sidebar and a main area.

It is one image for screen readers (`role="img"` with `label`). Put a greeting, three StatCards and a DataTable inside, or other real screens.

**Content:** the brand, the sidebar labels, the active item, the alt text and the main content. Use real-looking sample data, not lorem ipsum.
