# EmailCapture

One email field and one primary button in a row, for a waitlist, a newsletter or a "get the guide" offer. Max width 480px; the row wraps on phones.

The field has a visually hidden label and a sample placeholder. On submit it checks the address: a bad address shows the TextField error; a good one is sent and the form changes to a success line with the check icon (`role="status"`, so screen readers read it).

Use it on light surfaces (surface or surface-soft), not inside CtaBlock. Put a one-line note under it only when it answers a real worry ("No spam. Leave the list at any time.").

**Content:** the button label (verb first: "Join the waitlist"), and an optional label, placeholder, note, success message, error message and alignment (center in a centered section).
