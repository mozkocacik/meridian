# FeatureItem

One feature: a 48px icon tile, an H3 and one or two sentences.

The icon tile is `icon-tile` (48px) with radius-lg (10px), a line border, surface-raised fill and shadow-xs. The icon is 22px, stroke 1.8, ink-secondary. Title uses `heading-3`, body uses `body` in ink-muted.

Two variants:
- `plain` (default): no frame, as in the reference page. Use in FeatureGrid on surface-soft.
- `card`: adds a 1px line border, radius-xl (12px) and space-6 padding. Use when features sit on plain surface without a band.

**Content:** an icon (a name from Icon), a title and the description. Keep descriptions under 90 characters.
