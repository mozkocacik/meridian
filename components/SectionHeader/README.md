# SectionHeader

The eyebrow, H2 and lead that open a section. Max width 720px, left aligned (or `align: 'center'`).

- Eyebrow: `eyebrow` style in accent-text. One word or two.
- H2: `heading-1` (40px, -0.02em).
- Lead: `body-lg` (18px, 1.6) in ink-muted.

**Content:** an eyebrow, a title, a lead, and the heading level when it is not an H2 (H1 on a sub page such as Pricing, where it is the page title).
