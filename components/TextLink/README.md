# TextLink

A link inside running copy: accent-text, 500, underlined with a 3px offset.

Use it in body text, fine print and FAQ answers. Use `md-link` (no underline, ink-secondary) only in nav and footer lists, where the position shows it is a link.

**Content:** the label and the link. An external link has an arrow icon, opens a new tab and tells screen readers so. Write the label as the destination ("pricing details"), never "click here".
