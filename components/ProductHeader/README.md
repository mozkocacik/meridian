# ProductHeader

The top of a product page, in 5 and 7 columns.

Left: breadcrumb, product code (h1 at 52px) with the lifecycle badge, one-sentence description (`body-l`), KeyValueGrid with six specs, actions (Request quote, Datasheet, Compare) and a meta row (lead time, samples, warranty). Right: a drawing view switch, a link to the 3D model, the Annotation and its legend.

Below 1024px the columns stack: text first, then the drawing.

**Content:** code, state, description, six specs, actions, drawing and legend.
