# ProductHeader

The top of a product page. Left (5 of 12 columns): Breadcrumb, product name in `h1` with its LifecycleBadge, one-line description in `body-l` `text-2`, a SpecList with six key values, and the actions: primary "Request quote", secondary "Datasheet", tertiary "Compare", all large (48px). Right (7 columns): a SegmentedControl for Drawing, Photo and 3D, the file size of the 3D model, and the annotated drawing.

On phones the columns stack: information first, then media.
