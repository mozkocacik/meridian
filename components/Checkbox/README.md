# Checkbox

Selects one or more options in a filter or a form. 18px square, radius `r-1`, `border-strong` border. Checked: `accent` fill with an `on-accent` check.

In filter panels, a count in `data` (12px, `text-3`) sits at the right end of the row. The count is the number of results with that value.

**Content:** a label and, in filters, a count.
