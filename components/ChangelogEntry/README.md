# ChangelogEntry

One release on a changelog page: the date and version on the left in Geist Mono, the change on the right.

- Meta column 200px: date in `mono` ink-muted, version in `mono` ink-secondary. It moves above the body on phones.
- Body: an optional badge (accent "New", success "Improved", neutral "Fixed"), an H3 in `heading-3`, then one or two short paragraphs in ink-muted.
- Entries are split by a line border and space-10 padding, newest first.

**Content:** the date (shown text and ISO date), the version, a tag with its tone, the title and the body. The AnnouncementPill on the hero links here.
