# PricingCard

One plan: name, one-line description, the price, one button and a feature list.

- Card: surface-raised, line border, radius-2xl, space-8 padding, shadow-xs.
- `featured`: the border and a 1px ring turn `accent`, and the button is primary. Use it on one plan only. Others get a secondary button.
- Name: `faq-question` style (18px, 600). Description: `body-sm` in ink-muted.
- Price: `price` style (48px, 600, tabular figures) with the period in ink-muted. "Custom" is fine for sales-led plans.
- Features: check icons in accent-text, text in ink-muted, under a line. Start a higher plan with "Everything in Team, plus:".

**Content:** the plan name, description, price, period, features, an optional features title, a badge ("Most popular"), the featured state and the button label and link. Keep features to six lines or less.
